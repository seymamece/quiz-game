My Classes

Just type the class name with its number — e.g. 7-A — and the grade is detected automatically (7-A → Grade 7). The grade decides which topics the class sees in the quiz. Use 🎓 only if you ever need to correct it, ✏️ to rename, 🗑 to delete.

Students

Add the students who are in class today. You can paste several names separated by commas. Crossed-out names have already been picked this round. ✏️ edits a name (points are kept), × removes.

☁️ Cloud Sync

Prepare your yearly plan at home, open it at school. Class names, subjects, topics, questions and scores are stored in your own account. Student names are encrypted on this device first — the server only ever receives unreadable text, and never has your passphrase.

Backup & Move Between Computers

Your data (classes, students, subjects, topics, questions, scores) is saved in this computer's browser — it does not travel inside the HTML file. To use the quiz on another computer (e.g. home → school):

1. Click Export All Data below — a backup file will download.
2. Put that file in your Google Drive (or a USB stick).
3. On the other computer, open the quiz and click Import All Data to load the backup. Everything comes back exactly as it was. ✔

💡 Tip: export a fresh backup at the end of each day so your Drive copy always has the latest scores.

Which export do I need?
• This one (Export All Data) — everything: classes, student names, questions and scores. For moving your own setup between computers.
• Question Banks → Export — questions only, no student names or scores. For sharing your work with other teachers.

🗑 Trash

Anything you delete lands here and can be restored for 30 days. (Right after deleting, you can also just press Undo in the popup, or Ctrl+Z.)
